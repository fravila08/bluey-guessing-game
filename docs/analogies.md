# Non-Technical Analogies

- **The three files are a stage play.** `index.html` is the set (the furniture and where it stands). `style.css` is the paint, lighting and costumes. `script.js` is the actors following the script.
- **The secret number is a number written on a card and sealed in an envelope.** The game opens the envelope only when you win or run out of guesses.
- **The ids are name tags.** The script finds each piece of the page by its tag, so if a tag is changed, the script can't find that piece.
- **The pop-up closing is a doorbell.** However you leave the room (button, clicking outside, Esc), the same bell rings (the `close` event), and the staff reset the room for the next player.
- **The 400ms guards are a bouncer** who ignores someone knocking twice in a split second. This stops an accidental double-tap from skipping your result.
- **Duplicate and invalid guesses are a polite "try again".** They don't use up any of your 5 turns.
